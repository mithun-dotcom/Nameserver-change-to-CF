NS Bulk Updater

Auto-fetch nameservers from Cloudflare, then push to your registrar

How it works:
① Add or find each domain in Cloudflare → ② Cloudflare returns its assigned nameservers → ③ Push those nameservers to your registrar automatically.
1 Cloudflare Credentials

Needs Zone → Zone → Edit permission, scoped to your account.

Found on any zone's Overview page (right sidebar) or in the dashboard URL.

2 Source Registrar Credentials

Needs scopes domains:read + domains:write.

⚠ Namecheap requires your server's IP to be whitelisted. On Render, whitelist your service's outbound IP (see README).
ℹ Get credentials at developer.godaddy.com → API Keys. Use Production keys for live domains.
ℹ Enable API access per-domain at porkbun.com → Domain Management → API Access.
ℹ Generate your API key at dynadot.com → Account → API Settings. Rate-limited to 200/day.
